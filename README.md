# PropertyIQ
AI-powered property insight assistant that helps buyers understand a property using its listing, legal documents, and locality reports.

## Features
Ask questions about a property
Get answers from property documents
View the source of answers
Detect mismatches between listing and legal documents
Simple property dashboard

## Tech Stack
Python / TypeScript
RAG,
Embeddings,
Vector Database.
OpenAI-compatible APIs.
Next.js
